Pengaturan Google Sheets Sync

Masukkan URL Web App dari Apps Script Google Sheets Anda untuk mengaktifkan sinkronisasi otomatis.

Mode Operasional:

  • Jika Web App URL diisi: Data disimpan di Google Sheets + Cache Lokal.
  • Jika kosong: Aplikasi berjalan pada Demo Mode (LocalStorage HP).

Panduan Setup Google Sheets via HP Android

Langkah 1: Buat Google Sheet

  1. Buka Google Drive atau Google Sheets di HP.
  2. Buat Spreadsheet baru dengan nama: Keuangan Finanzio.
  3. Di Sheet1, buat Header pada baris ke-1: ID | Tanggal | Jenis | Kategori | Nominal | Catatan

Langkah 2: Tambah Google Apps Script

  1. Buka spreadsheet melalui Browser HP (Chrome) dengan centang "Situs Desktop" / "Desktop Site".
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua kode bawaan, lalu tempelkan (paste) kode Apps Script berikut:
function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var rows = data.slice(1);
  var result = rows.map(function(r) {
    return { id: r[0], date: r[1], type: r[2], category: r[3], amount: Number(r[4]), note: r[5] };
  });
  return ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var contents = JSON.parse(e.postData.contents);
  var action = contents.action;
  
  if (action === "create") {
    sheet.appendRow([contents.id, contents.date, contents.type, contents.category, contents.amount, contents.note]);
  } else if (action === "delete") {
    var data = sheet.getDataRange().getValues();
    for (var i = 1; i < data.length; i++) {
      if (data[i][0] == contents.id) {
        sheet.deleteRow(i + 1);
        break;
      }
    }
  } else if (action === "update") {
    var data = sheet.getDataRange().getValues();
    for (var i = 1; i < data.length; i++) {
      if (data[i][0] == contents.id) {
        sheet.getRange(i + 1, 2, 1, 5).setValues([[contents.date, contents.type, contents.category, contents.amount, contents.note]]);
        break;
      }
    }
  }
  return ContentService.createTextOutput(JSON.stringify({result: "success"})).setMimeType(ContentService.MimeType.JSON);
}

Langkah 3: Deploy sebagai Web App

  1. Klik tombol Deploy (Terapkan) > Deployment baru (New deployment).
  2. Pilih Jenis: Web App.
  3. Ubah Who has access (Siapa yang memiliki akses) menjadi: Anyone (Siapa Saja).
  4. Klik Deploy, berikan izin akses Google Account Anda.
  5. Salin URL Web App yang dihasilkan (berakhiran /exec).
  6. Buka menu **Pengaturan** di kanan atas web ini, paste URL tersebut dan klik Simpan.
